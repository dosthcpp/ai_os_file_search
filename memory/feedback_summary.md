# University of Liverpool Feedback Summary

## CSCK503: Machine Learning in Practice (Ongoing)
*   **Average Grade**: ~65%
*   **Key Improvement Areas**:
    *   **Analytical Depth**: Move beyond descriptive "how-to" to critical "why".
    *   **Justification**: Provide theoretical grounding for technical decisions (e.g., data imputation methods, feature typing).
    *   **Academic Rigor**: Avoid non-academic sources (blogs, AI tools) in citations. Link to module concepts directly.
