# Patent PoC 2: NFT Blockchain Mobile E-Consent

## 1. Invention Title
Mobile e-consent form using NFT blockchain technology and AI technology

## 2. Key Concepts
- **Hyperledger Fabric Integration**: Distributed ledger for immutable consent records.
- **NFT Uniqueness**: Minting each consent form as an NFT to prevent duplication and ensure ownership.
- **Smart Contracts**: Automated execution of consent terms (e.g., first-come-first-served logic for school bus registration).
- **AI Security Layer**: Real-time masking of PI before block commitment.

## 3. Workflow
1. Teacher creates consent form.
2. Form is tokenized as an NFT.
3. Parent signs using biometric authentication.
4. Smart contract validates and records to the blockchain.
