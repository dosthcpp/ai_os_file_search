# Patent PoC 2: NFT Blockchain-Based E-Consent & AI Integrity Verification

## 1. Overview
This PoC implements the lifecycle of an e-consent form using NFT technology to ensure uniqueness and ownership, integrated with Hyperledger Fabric logic (simulated).

## 2. Key Features
- **NFT Issuance**: Each signed document is minted as a unique token.
- **Smart Contract Logic**: Automated execution of consent terms without intermediaries.
- **AI Behavior Verification**: Analyzing signature patterns to detect anomalies.
