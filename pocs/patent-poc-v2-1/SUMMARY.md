# Patent PoC 1: AI E-Consent System with Sandbox Phishing Detection

## 1. Invention Title
AI-Powered E-consent Auto-Detection, Encryption, Biometric Signature & Sandbox-Based Phishing Detection System

## 2. Key Modules
- **AI PI Detector**: BERT-based detection of RRN, bank accounts, and sensitive info.
- **Dynamic Encryption**: RSA-OAEP and AES-256 layering based on risk levels.
- **Biometric Signature**: Flutter-based mobile signing with AI behavioral anomaly detection.
- **Phishing Sandbox**: Isolated execution of APKs to analyze network calls and data exfiltration.

## 3. Implementation Plan
The PoC simulates the "Single-Pass" logic where a document is indexed for search while simultaneously audited for security risks.
