# Patent PoC 1: AI-Based Personal Information Detection & Sandbox Phishing Detection

## 1. Overview
This PoC demonstrates the integration of AI-driven personal information detection (BERT/Sequence Labeling) and a sandbox-based environment for analyzing suspicious mobile applications (APKs) as described in the patent.

## 2. Key Features
- **AI PI Detector**: Automatically scans documents for patterns like Resident Registration Numbers (RRN), credit card numbers, and bank accounts.
- **Phishing Sandbox**: A mock environment to analyze APK behaviors, network requests, and permission abuses.
